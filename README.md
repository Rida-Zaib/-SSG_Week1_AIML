# Skill Set Go EduTech — AI/ML Track — Week 1

Foundation Phase: Python, Mathematics & Machine Learning Foundations

This repo contains all 4 tasks for Week 1 of the Skill Set Go EduTech AI/ML
internship track, merged from individual task repos into one place.

## Tasks

| Task | Folder | Description | Deliverable |
|---|---|---|---|
| 1.1 | [`1.1_python-fundamentals/`](./1.1_python-fundamentals) | Python exercises covering variables, loops, functions, OOP, lists, dictionaries, file handling, and exceptions | GitHub repo with solved exercises |
| 1.2 | [`1.2_data-cleaning-eda/`](./1.2_data-cleaning-eda) | Cleaning a sample sales dataset and exploring it with NumPy, Pandas, and Matplotlib | Jupyter notebook with cleaned dataset + visualizations |
| 1.3 | [`1.3_math-for-ml/`](./1.3_math-for-ml) | Applied problems in statistics, probability, linear algebra, and calculus | Notebook of worked solutions |
| 1.4 | [`1.4_ml-models/`](./1.4_ml-models) | Two scikit-learn models: a regression model and a classification model | Notebook with two trained models + evaluation report |

Each folder has its own `README.md` with setup and run instructions specific
to that task.

## How to use this repo

```bash
git clone https://github.com/Rida-Zaib/SSG_Week1_AIML.git
cd SSG_Week1_AIML
```

Then open whichever task folder you want and follow its own README.
