# Task 1.1 — Python Fundamentals Assignment

## Overview
This task covers core Python concepts: variables, loops, functions, OOP, lists,
dictionaries, file handling, and exceptions. It's built as a small student grade
management program that demonstrates each concept in a practical way.

## What it does
- Defines a `Student` class (OOP) with methods to calculate average and letter grade
- Uses functions to add students, find the top student, and compute class-wide stats
- Uses a dictionary to build a name-to-grade lookup
- Handles exceptions (like division by zero) gracefully instead of crashing
- Reads and writes data to a file (`students.json`) using file handling

## Files
- `main.py` — the full solution
- `students.json` — generated automatically when the script runs (saved student data)

## How to run
```bash
python3 main.py
```

## Sample output
The script prints each student's average and letter grade, the top student in the
class, overall class statistics, and a demonstration of safe division handling.
